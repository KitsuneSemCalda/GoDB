# GoDB

GoDB is a hobby project to build a database that runs with only the Go runtime. It is an opportunity to explore how a database works by building one in Go.

## Project status

GoDB is at the beginning of development. There is no database implementation or installation procedure in this repository yet.

> [!WARNING]
> This hobby project is intended to be developed without AI assistance or vibe coding.
> This is not a political statement for or against AI; the focus is on the **nerdic way** of learning and building.
